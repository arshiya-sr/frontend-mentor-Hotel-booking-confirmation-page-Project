## Overview

### The challenge

Users should be able to:

- View the optimal layout for the interface depending on their device's screen size
- See hover and focus states for all interactive elements on the page
- Open and close the navigation menu on smaller screens (optional JavaScript)
- Copy the Wi-Fi password to their clipboard using the copy button (optional JavaScript)

### What I learned

This project taught me several things:

- I learned, with the help of AI, to use CSS to do difficult and complex things that would normally require JavaScript.
- I implemented the hardest flex layouts I've ever done.
- I worked with CSS custom properties. 
- And in the end, the most interesting animations I've built so far were in this project.

### Continued development

I'll continue working on:

- More responsive and thoughtful design and workflow.
- Expanding this into a larger project, integrating it into bigger ones, or using it as a model for future projects.
- Improving animations and responsiveness.
- Some components may be rebuilt after I learn JavaScript.
